# 免费代理实测清单

本文件记录用 UPI Workbench 自带的本地探测逻辑实测过的免费代理。免费代理存活时间极短，**每次使用前必须在“代理库”页面重新测试**，不要直接依赖本文件中的结果。

## 探测方式

- 由后端本机发起，经代理访问固定目标 `https://api.ipify.org?format=json`，超时 6 秒。
- 连续两次探测都成功才记为“可用”，单次成功视为偶发。
- 出口 IP 归属地用 `ip-api.com` 交叉确认。
- 代理地址不发送给任何第三方检测服务。
- ytc 新提链只接受 HTTP / HTTPS / SOCKS5，SOCKS4 会被拒绝。

| 协议 | 地址 | 延迟 | 出口 IP | 归属 | ytc |
| --- | --- | --- | --- | --- | --- |
| socks5 | `144.24.111.128:1088` | 1.6 秒 | 144.24.111.128 | 印度 · Oracle Cloud (AS134926) | 可用 |

实测记录：连续 4 次探测均成功，延迟 1.6 ~ 2.1 秒。该节点为数据中心 IP（hosting），接码和提链可用，但不适合需要住宅 IP 的场景。

### 2.3 来自 rola-ip.co/zh/tools/free-proxy-list/

- 页面当前显示在线代理 0 条，并提示“无法加载代理 IP 列表”。
- 印度国家页 `country/in/` 为前端渲染，HTML 中没有任何 IP 数据。
- 官方免费 API `https://rola-ip.co/api/v1/free-proxy-list?country=IN` 返回 `{"code":4000,"message":"请先登录"}`，与页面宣称的“匿名用户每分钟 10 次请求”不符。
- 结论：目前无法匿名获取其免费代理数据。

## 三、结论与建议

1. 免费代理的可用率普遍低于 5%，印度节点尤其差。
2. 大量节点存在 TLS 中间人（证书被替换），这类代理对接 ytc 完全不可用，只有本机自测能识别。
3. 站点自报的在线率、匿名等级、延迟不可信，必须自行实测。
4. 印度 SOCKS5 目前只有 `144.24.111.128:1088` 通过两次连续实测。
5. 建议：批量测试后再启用代理库；代理库启用后所有新 ytc 任务都会走库内代理，不可用代理会导致新提链全部失败。
6. 长期使用建议改用付费住宅代理或固定 ISP 代理。
