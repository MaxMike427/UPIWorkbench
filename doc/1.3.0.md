# V1.3.0 设计与验收清单

## 已确认范围

- 账号库删除固定的 0217、AI 批发商购买按钮，保留供应商下拉和一个购买按钮；来源文件分组显示账号数量，精确筛选并与搜索、分页共用。
- 代理库增加 711proxy 动态代理 API URL 配置、手动拉取。新建任务选择系统代理时，在首次启动前自动取一次；失败阻止提交，不回退直连。已有外部订单恢复不重新取代理。
- 设置中的代理来源和三类 CDK 表单合并为一个供应商配置表格向导。按顺序选择提链或提链支付一体、供应商、代理来源、独立支付（按需）、接码开关与供应商、凭证，最后确认保存。后续问题只在前置选项完成后出现。
- 保存后显示简略流程、凭证保存状态、购买/兑换入口、数据库配置键；取消不写入，上一步允许重选。凭证不回显，留空可保留同一供应商已保存的值。
- 先以 ytc 和 Handy 为可执行配置，其它服务商保留目录占位并明确提示未接入。保留现有适配器与旧任务的兼容，不增加其它供应商真实联调。
- 源码版本改为 1.3.0；不创建发布标签，不在本次实现中自动启动真实提链/支付/接码任务。

## 数据与兼容

- 继续使用 FastAPI 路由 → services → aiosqlite 的结构，前端保留 Alpine.js `app()`、`api()`、`busy` 和 toast 模式，不增加依赖。
- 供应商流程原子保存到现有 `configs` 表；独立供应商凭证使用 `provider_credentials.<id>.cdk`，并同步当前选择的旧配置键供旧入口兼容。
- 系统代理/服务商代理映射为 `provided`/`provider`；ytc 外部请求映射为 `provided`/`internal`。
- 任务保存流程与动态代理配置快照，已创建任务不会因设置变化而换供应商。首次自动拉取后锁定每个成员的代理；继续原订单沿用原快照。
- API URL 含鉴权参数，按密钥处理；允许 711proxy 控制台生成的 `*.711proxy.com`，以及实际动态接口使用的 `*.rotgbapi.trustsource.live:8089` 主机，禁止其它域名、内网、重定向及无界响应。错误不返回 URL、鉴权参数或供应商原始正文。

## 风险与边界

- 711proxy 文档要求控制台生成提取 URL；优先支持 TXT 每行一个 host:port，同时兼容 JSON 代理列表。协议由配置选择；不猜测未公开的 URL 生成参数。
- 711proxy 提取请求共用至少 1 秒间隔，单次最多 900 条；限制作用于当前工作台进程，不协调多个独立部署实例。
- IP 白名单由用户在 711proxy 控制台配置。白名单代理只对工作台所在服务器有效；传给远程提链服务之前需确认它能访问该代理，界面明确提醒。
- ytc 的登录凭证是 `ohk_` API Key，不是购买后未兑换的 CDK。向导提供购买和兑换入口并标明字段用途。
- 接码实际由 Handy 完成，摘要不能把 Handy 误标为 ytc 的内置能力。
- 保存失败保持旧配置完整；拉取失败保留原代理库并不提交第三方任务。

## 验证

使用隔离 SQLite、第三方替身和 Playwright 验证，不调用真实付费 API。涵盖来源筛选、逐步显隐、跳过支付/接码、取消与返回、原子保存、凭证隔离与脱敏、711proxy 格式/失败、安全校验、首次启动自动拉取和恢复不换代理、旧任务兼容。

## 操作说明

1. 账号库选择来源文件，列表只显示该文件导入的账号；选择“全部来源文件”恢复全库。来源分组跨所有分页统计，搜索与筛选同时生效，切换来源不清空已选账号。
2. 设置 → 供应商配置 → 配置供应商/修改配置。选择当前项目后，下一问题出现；提链支付一体不另选支付，接码选“否”不另选接码供应商。
3. ytc 输入已兑换的 `ohk_` API Key，Handy 输入 CDK。已保存的同供应商凭证可留空保留；占位供应商允许不填凭证保存清单，但不能启动自动任务。点击“查看配置清单”检查后“确认保存”；上一步重选，取消配置不写入。
4. 保存摘要例如 `ytc 内置代理 · 提链+支付 · Handy 接码`。摘要后附各供应商购买/兑换链接、保存状态、实际 SQLite 路径和 `configs` 表配置键。真实值不会填回输入框。
5. 代理库 → 711proxy 动态代理：复制官方控制台生成的提取 URL，选择相同协议（HTTP/HTTPS/SOCKS5），启用“系统代理新任务启动前自动取链”，保存。点击“拉取并添加”会先提示可能消耗额度；保存本身不拉取。
6. 为系统代理新任务保存动态配置快照，首次启动取一次并锁定成员代理。服务商代理不调用 711proxy。拉取失败任务仍为待执行，可以修正网络/白名单后重试；想换取链 URL 应新建任务。继续和失败重试沿用原代理，不保证超过供应商粘性会话时长仍是同一出口 IP。

## 新接口

以下接口均要求管理员 Bearer Token 或有效登录会话。运行路径由 `UPI_DB_PATH` 决定。

| 接口 | 请求 | 返回与错误 |
|---|---|---|
| `GET /api/credentials/sources` | 无 | `items: [{source_file,total}]`，全库分组计数；空来源为空字符串 |
| `GET /api/credentials` | 新增 `source_file`，可与 `keyword/page/page_size` 同用 | 精确文件名匹配；不传参数为全库，传空字符串为未记录来源；原分页契约不变 |
| `GET /api/configs/supplier` | 无 | 流程选项、summary、executable、凭证保存状态/配置键/公开链接、storage；无真实密钥 |
| `PUT /api/configs/supplier` | `flow_type: extract/extract_pay`、`extract_provider`、`proxy_source: system/provider`、可选 `payment_provider`、`sms_enabled`、可选 `sms_provider`、`credentials: {供应商ID:新凭证}` | 完整校验后原子保存；空值保留此供应商凭证；400 选项组合/凭证无效，422 类型或长度错误 |
| `GET /api/proxies/dynamic` | 无 | `provider,protocol,enabled,url_saved,host,storage_key`；不返回 URL 的路径和鉴权参数 |
| `PUT /api/proxies/dynamic` | `api_url`（空则保留）、`protocol: http/https/socks5`、`enabled` | 保存配置，不发第三方请求；400 URL 非官方/开关缺少 URL，422 格式错误 |
| `POST /api/proxies/dynamic/fetch` | 无 body | `fetched,items,total,enabled`，追加不覆盖，代理凭证脱敏；400 网络/白名单/额度/响应格式错误，旧代理库不变 |

配置保存请求示例（只使用测试占位值，不代表真实凭证）：

```json
{
  "flow_type": "extract_pay",
  "extract_provider": "ytc",
  "proxy_source": "provider",
  "sms_enabled": true,
  "sms_provider": "handy",
  "credentials": {"ytc": "ohk_TEST_ONLY", "handy": "TEST_ONLY_CDK"}
}
```

凭证按 `provider_credentials.<id>.cdk` 隔离并同步当前旧键。第一次保存先归档原供应商凭证，关闭接码或改选供应商不会丢失旧值。动态代理 URL 为 `proxy.dynamic.api_url`，协议/开关为 `proxy.dynamic.protocol` / `proxy.dynamic.enabled`；任务动态快照只保存在本地数据库，不暴露给列表、详情或报告。
