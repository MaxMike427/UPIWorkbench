# V1.1.0 实施计划

## 已确认决策

- 未接码支付成功账号进入成功库，状态“已成功未接码”；允许 TXT，不自动推送，也不生成假 JSON。
- 代理库关闭/为空阻止新提链；已提交订单仍查询原单，已支付账号可继续接码。
- sub2api Admin Key 使用官方 `x-api-key` 鉴权；可用模型不擅自修改远端分组；接码成功任务可自动推送，成功库同时支持手动单选/多选推送。
- 取消账号只作用于未执行候选列表，不取消已有外部支付。
